# Онлайн платформа за състезания по програмиране

Дипломен проект на Мирослав Генов.

Платформа за провеждане на състезания по програмиране за ученици, по модела на „Аз мога – тук и сега“. Поддържа два вида задачи:

- **с автоматична проверка** – решението се компилира и пуска срещу тестове;
- **с оценяване от жури** – проектът (приложение, сайт, игра) се предава като GitHub хранилище и се оценява по критерии.
